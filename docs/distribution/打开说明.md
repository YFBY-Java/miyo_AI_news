## 启动工作台

进入包含 `voice-library/` 的工程根目录。在当前 Windows 机器的 PowerShell 中执行：

```powershell
Set-Location 'D:\codex_work\AI创作\miyo_AI_news'
npm ci
npm run dev
```

使用Node.js 20或以上，当前开发机器使用Node.js 24。`npm ci`按照锁文件安装依赖，需要网络；保持开发依赖完整，后台worker会使用`tsx`。工作台地址为 `http://127.0.0.1:3002`。

导出视频还需FFmpeg/FFprobe和Playwright无头浏览器。目标机器未安装当前Playwright对应浏览器时，安装项目依赖后可按需执行：

```sh
npx playwright install chromium
```

配音控制器需要Python 3。已有音频和视频文件可独立播放。工作台的本地工具状态只是初步检查；迁移后应先复制项目、保留一段口播做小样验证。

## 琪亚娜新配音与历史音轨复用

声线参考素材已整合到项目内 `voice-library/`，克隆或移动整个项目即可恢复默认声线路径；新口播使用的Qwen3-TTS模型、MLX Python环境和系统工具需在目标机器准备。这些资源依赖机器与系统架构，具体配置见[配音流水线](../VOICE.md)与[运行与维护](../OPERATIONS.md)。

原 Mac 机器继续使用时可以使用已有MLX环境和模型；该历史环境尚不能当作当前 Windows 的已安装环境。换机器时新琪亚娜口播需要适用的本地推理环境和完整模型（包括tokenizer、speech_tokenizer和配置）；程序离线加载，不会自动下载缺失模型。晓晓声线使用edge-tts在线合成，需要已有工具和网络。

星铁历史原稿在未设置`MOYO_MLX_PYTHON`、`MOYO_KIANA_MODEL`、`MOYO_KIANA_VOICE_DIR`、`MOYO_KIANA_REFERENCE`、`MOYO_KIANA_REFERENCE_TEXT`、`MOYO_KIANA_PRESETS`时，可以使用包内fixtures原速音轨重新准备配音，复用分支无需MLX模型，但需要Python及FFmpeg/FFprobe。仅在需要新推理时配置真实路径，不要在普通启动时无条件设置这些覆盖变量。

解压位置变化会改变整期配音缓存的身份校验；旧WAV仍然保留，但工作台可能需要再次「合成配音预览」建立匹配计划。新写口播也不能保证跨机器复用旧缓存。
